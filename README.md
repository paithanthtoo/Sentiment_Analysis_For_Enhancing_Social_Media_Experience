# Sentiment Analysis for Enhancing Social Media Experience (EmotiSense)

A full-stack web application designed to automatically detect toxic comments, spam, malicious/phishing URLs, and NSFW images in real time to foster a safer and healthier online community[cite: 1, 3]. Presented at the **6th IMC Project Show (2026)**.

---

## 🚀 Features

* **Real-Time Sentiment Scoring:** Utilizes NLTK VADER and custom emoji valence mapping to classify text and emojis into positive, neutral, and negative sentiment categories.
* **Multi-Modal Content Moderation:** Automatically scans for malicious URLs/phishing patterns and detects NSFW images using Hugging Face transformer/computer vision models.
* **Interactive UI & "Clear Mode":** Features a dynamic full-stack interface with color-coded sentiment indicators and a dedicated "Clear Mode" to protect users from toxic material[cite: 1, 3].
* **Data Analytics & Reporting:** Includes data quality charts and performance metrics to track system accuracy[cite: 1].

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask, SQLite[cite: 1]
* **AI & NLP:** NLTK (VADER), Hugging Face Transformers, OpenCV[cite: 1, 3]
* **Frontend:** HTML5, CSS3, JavaScript[cite: 1]
